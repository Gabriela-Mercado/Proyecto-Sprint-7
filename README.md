# Proyecto-Sprint-7
## Este es un proyecto de herramientas de sofware para principiantes, la idea es que los estudiantes logren crear una página web con los conocimientos básicos adquiridos en la teoría y práctica que tuvieron durante las lecciones de este curso.
## El proyecto analiza los datos de una estadística de venta de vehículos, con la página queremos lograr que los productos en este caso los coches sean atractivos para el público y alguien se interese en hacer una compra.
## Tiene algunas visualizaciones como gráficos para que los clientes puedan ver que auto les conviene mejor o se adapta a sus necesidades y esto tiene como objetivo que se puedan lograr ventas.
### Para este proyecto es necesario tener lo siguiente:
